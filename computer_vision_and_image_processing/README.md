# Computer Vision and Image Processing

Generic Python implementations of classical computer-vision and image-processing methods.

Topics covered:
- Grayscale conversion and histogram analysis
- Histogram equalization
- Threshold-based segmentation
- Object measurements: area, centroid, bounding box and orientation
- Horizontal and vertical image projections
- Run-Length Encoding (RLE) and reconstruction
- Haar Cascade face detection

The code is organized as a clean public portfolio implementation and does not reproduce course-specific datasets or submission files.
